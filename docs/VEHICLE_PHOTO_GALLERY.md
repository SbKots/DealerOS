# Фотогалерея автомобиля

Галерея доступна в карточке выбранного автомобиля в разделе «Приёмка». Обложка также используется в реестре, карточке и блоке внимания на обзоре.

## Возможности

- множественный выбор и drag-and-drop upload с прогрессом, локальной ошибкой и повтором;
- JPEG/PNG/WebP до 8 МиБ и 25 MP; формат определяется декодированием, а не расширением;
- автоматическое исправление EXIF orientation и удаление EXIF/GPS при перекодировании;
- thumbnail 480, medium 1280 и large 2560 px по длинной стороне без upscale;
- категории ракурсов, подпись, focal point, обложка, порядок и отбор в объявление;
- полноэкранный `contain` lightbox со стрелками и клавишами `←`/`→`/`Esc`;
- ссылочный импорт фотографий дефектов из завершённых осмотров;
- desktop/tablet/mobile layout и read-only режим без управляющих permissions.

## Права

- `vehicles.photos.view` — metadata и приватное скачивание;
- `vehicles.photos.upload` — загрузка и импорт из осмотра;
- `vehicles.photos.manage` — metadata, порядок, обложка, отбор и удаление.

Tenant и разрешённый branch выводятся из актуального JWT и повторно проверяются application/store слоями. Клиент не передаёт organization или branch. Максимум — 100 фотографий на автомобиль. HEIC/HEIF в текущей версии не поддерживается.

## Demo

GitHub Pages использует только сгенерированные синтетические изображения из `apps/web/public/demo/gallery`. Действия меняют React state и сбрасываются после обновления страницы; файлы не отправляются на API и не попадают в MinIO.
