# Глоссарий

- **Цифровой паспорт** — стабильная карточка конкретного автомобиля и проверяемая история связанных действий.
- **Поступление** — регистрация основания и данных автомобиля перед физической складской приёмкой.
- **Приём на склад** — подтверждённое бизнес-действие, после которого автомобиль получает статус `InStock` и складской номер.
- **Филиал** — организационная единица арендатора; пользователь видит только разрешённые филиалы.
- **Площадка/локация** — физическое место хранения внутри филиала; появится в следующем складском срезе.
- **Tenant/арендатор** — независимая организация в общей установке DealerOS.
- **Плановая цена закупки** — согласованная/ожидаемая сумма приобретения; не заменяется будущими фактическими расходами.
- **Аудит** — append-only след критического действия с автором, временем, объектом и correlation ID.
