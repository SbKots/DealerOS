# UX/UI-редизайн DealerOS 1.0

## Цель

Собрать функциональные модули DealerOS в единый B2B-интерфейс для длительной ежедневной работы, не меняя доменные правила, API и модель данных.

## План

1. Заменить горизонтальную навигацию на permission-aware оболочку: постоянный sidebar, компактный tablet-вариант и mobile drawer.
2. Ввести общие токены и компоненты для типографики, поверхностей, кнопок, форм, статусов, таблиц, загрузки и пустых состояний.
3. Добавить «Обзор», агрегирующий только существующие API автомобилей, CRM, визитов, бронирований, сделок и экономики.
4. Сделать автомобиль главным объектом: визуальная карточка, читаемый статус и шкала полного lifecycle.
5. Перекомпоновать существующие очереди, формы и detail views без изменения команд и разрешений.
6. Проверить все роли и основные состояния на desktop, tablet и mobile, затем прогнать backend, frontend и E2E.

## Ограничения решений

- Изображения автомобиля показываются только из уже доступных private media; до появления подходящей связи используется нейтральный локальный placeholder.
- Dashboard не вычисляет новую бизнес-логику и не сохраняет агрегаты: все значения формируются на клиенте из доступных read API.
- Внутренние enum, UUID и snapshot-структуры остаются неизменными; пользовательские подписи переводятся на русский только на уровне представления.
- Новая UI-библиотека не добавляется. Дизайн-система построена на React-компонентах, inline SVG и CSS variables проекта.
