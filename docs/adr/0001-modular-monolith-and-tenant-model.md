# ADR-0001: модульный монолит и shared-schema tenant model

Статус: принято, 2026-07-12.

## Решение

Использовать ASP.NET Core 10 modular monolith, React/TypeScript и PostgreSQL 17. Tenant-owned строки содержат `OrganizationId`; организация определяется JWT. Данные модулей разнесены по PostgreSQL schemas. Один EF infrastructure adapter используется как практичный старт, при этом домен и application ports остаются в отдельных проектах.

## Причины

Бизнес-модель меняется, а критические операции автомобиля, аудита и денег требуют простых транзакций. Микросервисы и брокер увеличат операционную стоимость без текущей выгоды. Общая БД соответствует масштабу модельного клиента и позволяет усиливать правила constraints/indexes.

## Последствия

Плюсы: быстрые вертикальные срезы, атомарность, простой локальный запуск. Минусы: дисциплина границ не обеспечивается отдельными БД; её контролируют project references, ports и review. При доказанной нагрузке/автономности модуль можно выделить через contracts + outbox.
